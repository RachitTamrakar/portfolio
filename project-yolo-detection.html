YOLO Object Detection System

Sole Developer • Bosch Australia Manufacturing Solutions • 2024

Python PyTorch YOLO OpenCV Transfer Learning Computer Vision

Real-time YOLO object detection on manufacturing line

Overview

Impact: Built automated ML pipeline that cut model training time by 2× for surgical-grade product detection, delivering high-reliability real-time inference on production line

Developed a complete end-to-end machine learning system for detecting and localizing surgical-grade products on a manufacturing line. As the sole developer, I built the entire pipeline from data collection through model deployment, optimizing for both accuracy and real-time performance.

The Challenge

Deploying deep learning on a production line requires balancing multiple constraints:

  • Surgical-Grade Accuracy: False negatives or positives could compromise product quality and patient safety
  • Real-Time Performance: Must process images at production line speeds without bottlenecks
  • Limited Training Data: Manufacturing environments don't generate large labeled datasets naturally
  • Deployment Constraints: Industrial PCs have limited GPU resources compared to development machines
  • Rapid Iteration: Production line changes require quick model updates and retraining

Technical Implementation

Automated Data Pipeline

Built complete dataset automation infrastructure to accelerate development:

  • Image Collection: Automated capture from production cameras with configurable triggers
  • Labeling Workflow: Streamlined annotation process using custom tools and batch operations
  • Data Augmentation: Programmatic generation of training variations (rotation, lighting, occlusion)
  • Version Control: Dataset versioning to track model performance against different data versions

Impact: Reduced model training time by 2× through automation of data collection and preprocessing

Model Architecture & Training

Optimized YOLO model for manufacturing environment constraints:

  • Transfer Learning: Started from small YOLO backbone pretrained on general objects
  • Model Optimization: Pruned and quantized for 1.5× inference speedup while maintaining accuracy
  • Custom Anchors: Tuned anchor boxes specifically for product geometry and camera angles
  • Loss Function Tuning: Weighted loss to prioritize precision over recall for safety-critical application

Deployment & Integration

Integrated model into production vision system:

  • PyTorch model exported to ONNX for optimized inference
  • Real-time detection pipeline with OpenCV preprocessing
  • Confidence thresholding tuned for surgical-grade reliability
  • Fallback logic for edge cases and anomalies

Technical Decisions & Problem Solving

YOLO vs Traditional Computer Vision

Evaluated deep learning vs classical approaches and chose YOLO because:

  • Robustness: Handles lighting variations and product orientation better than hand-tuned algorithms
  • Adaptability: Retraining with new data is faster than re-engineering traditional pipelines
  • Localization: Bounding box predictions provide precise position for downstream automation
  • Performance: Modern YOLO variants achieve real-time speeds on modest hardware

Model Size vs Speed Tradeoff

Initial model was too slow for production cycle time. Optimization strategy:

  1. Profiled inference pipeline to identify bottlenecks (model forward pass dominant)
  2. Switched to smaller YOLO variant and retrained (30% speedup, minimal accuracy loss)
  3. Quantized model from FP32 to INT8 (additional 40% speedup)
  4. Optimized preprocessing pipeline with vectorized OpenCV operations
  5. Result: 1.5× overall inference speedup meeting production requirements

Handling Limited Training Data

Manufacturing environments don't naturally generate large labeled datasets:

  • Transfer Learning: Pretrained backbone provided strong feature extraction with less data
  • Aggressive Augmentation: Programmatically generated 10× more training samples from base images
  • Active Learning: Prioritized labeling of model failure cases to improve weak areas
  • Synthetic Data: Explored rendering synthetic products for edge case scenarios
