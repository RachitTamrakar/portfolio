Multi-Station Vision Inspection System

Undergraduate Engineer | Bosch Australia Manufacturing Solutions | 2024-2025
Confidentiality Notice: Due to confidentiality, photos and videos cannot be shared. Any photos shown are of similar systems.

System

  • Production machine-vision inspection system deployed on a live biodegradable packaging line
  • Six inspection stations operating in parallel
  • 4-12 cameras per station
  • Approx. one product inspected every ~600 ms
  • Integrated with PLC-controlled automation equipment
  • Deployed on an ~$8M production line and currently in use

My Role

  • Primary developer of the vision inspection application
  • Designed and implemented the core C# inspection application
  • Built multithreaded software handling camera acquisition, image processing, PLC communication over PROFINET, and operator user interface
  • Added SQL logging for inspection measurements and defect traceability
  • Worked with automation engineers on PLC handshakes and sequencing

Deployment & Impact

  • Commissioned and validated on the production floor
  • Application remains in production use
  • Reused internally as a template for future vision systems
