Fruit Navigation and Mapping Robot

Autonomous mobile robot combining YOLO object detection, Extended Kalman Filter localization, and full SLAM for environment mapping

Monash University - Intelligent Robotics • 2024
Python YOLO OpenCV Extended Kalman Filter SLAM State Machines Autonomous Navigation

The Challenge

The objective was to enable a mobile robot to autonomously map an unknown environment and locate specific fruit objects without any prior knowledge of the space. This required integrating perception, localization, and navigation systems into a cohesive autonomous agent.

Complete autonomous navigation demonstration

Perception

Detect and classify multiple fruit types in real-time with varying lighting and backgrounds.

Localization

Track robot position accurately in unmapped environment using noisy sensor data.

Navigation

Plan collision-free paths through unknown obstacles while simultaneously building a map.

Integration

Coordinate all subsystems in real-time with robust state machine architecture.

Perception System

Custom YOLO Object Detection

I trained a custom YOLO model specifically for fruit detection in the robot's operating environment. To create a robust training dataset, I generated synthetic images with random backgrounds and distractor objects, improving the model's generalization capability.

Dataset Creation

Generated synthetic training images with varied backgrounds, lighting conditions, and distractor objects to improve model robustness. Augmented with real-world images from test environment.

Model Training

Trained compact YOLO model optimized for real-time inference on embedded hardware. Balanced accuracy and speed for live autonomous operation.

Real-Time Detection

Integrated OpenCV for camera interface and preprocessing. Achieved reliable fruit detection and classification during autonomous navigation.

Localization & Sensor Fusion

Extended Kalman Filter Implementation

Implemented an Extended Kalman Filter (EKF) for sensor fusion, combining wheel odometry and landmark observations to accurately track the robot's position in the unmapped environment.

Sensor Fusion

Combined wheel encoder data with visual landmark detections using EKF framework. Handled nonlinear motion models and sensor noise characteristics.

Parameter Optimization

Automated parameter sweeps to tune filter gains and noise models. Optimized for best localization accuracy in test environment.

Reliable Estimation

Achieved consistent position tracking even with noisy sensor measurements and wheel slip. EKF provided uncertainty estimates for navigation decisions.

Navigation & Mapping

Full SLAM Implementation

Implemented complete Simultaneous Localization and Mapping (SLAM) system, allowing the robot to build a map while simultaneously using that map to localize itself.

Ray-Casting Navigation

Implemented ray-casting algorithm for obstacle avoidance and path planning. Robot evaluates multiple potential trajectories in real-time, selecting paths that avoid obstacles while progressing toward goal.

Map Building

Incrementally constructed occupancy grid map as robot explored environment. Integrated sensor data to mark free space, obstacles, and unknown regions.

Autonomous Exploration

Robot autonomously explored unmapped areas, balancing exploration of unknown space with exploitation of known paths to fruit targets.

System Integration

State Machine Architecture

Integrated all subsystems—perception, localization, navigation, and mapping—into a unified state machine architecture that coordinated autonomous operation from start to goal.

1

Exploration State

Robot explores environment, building map and searching for fruit targets using SLAM.

2

Target Detection

YOLO perception system identifies fruit objects, triggering navigation planning.

3

Path Planning

Ray-casting navigation generates collision-free path to target using current map.

4

Autonomous Execution

Robot navigates to fruit while continuously updating localization and map.

Real-Time Coordination

All modules operated concurrently with careful data synchronization. State machine handled transitions between exploration, navigation, and target acquisition modes while maintaining system stability.
