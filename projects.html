Liquid Rocket Engine Development & Testing

  • Analysis Tools: Created Python-based post-processing pipeline for performance analysis and visualization, enabling rapid design iteration
  • Automation: Programmed automated test sequences reducing manual operations and improving repeatability while minimizing human error
  • Team Leadership: Managing cross-functional team for propulsion system development, coordinating between design, manufacturing, and testing phases

SolidWorks, Python, C, STM32, LabVIEW, MATLAB, CNC Machining, Propulsion Theory, CFD Analysis

Impact:

Reduced test setup time by 40% through automation. Successfully conducted multiple hot-fire tests with comprehensive data collection enabling rapid iteration on engine design. Implemented safety protocols that have maintained perfect safety record across all testing operations.

Autopilot for Autonomous Combat Vehicles

Embedded Systems Robotics

Developed a comprehensive autonomous navigation system for combat vehicles competing in RoboMagellan competitions. The system integrates multiple sensors and implements advanced algorithms for real-time decision making in outdoor environments with dynamic obstacles and varying terrain conditions.

Key Features:

  • Multi-Sensor Fusion: Integrated GPS, IMU, LiDAR, and camera data using Extended Kalman Filter for robust localization with sub-meter accuracy even with GPS dropout
  • Path Planning: Implemented A* and RRT algorithms for dynamic obstacle avoidance and optimal path generation in real-time
  • Computer Vision: Developed cone detection system using OpenCV and custom CNN achieving 95% detection accuracy at 30fps for navigation waypoints
  • Control Systems: Designed PID controllers for steering and throttle with adaptive tuning based on terrain conditions (grass, gravel, pavement)
  • Real-time Processing: Optimized C++ codebase to run on embedded ARM processor with <50ms loop time for all sensor processing and control
  • Safety Systems: Implemented failsafe mechanisms including emergency stop, GPS fence, and sensor validation for safe operation
  • System Integration: Designed and built complete electronics stack including power distribution, motor controllers, and sensor interfaces

Technical Stack:

C++, Python, ROS2, OpenCV, TensorFlow, ARM Cortex-M7, GPS, IMU, LiDAR, Raspberry Pi

Results:

Successfully navigated complex outdoor courses with 90% completion rate, handling varied terrain and dynamic obstacles. System processed sensor data and made navigation decisions in real-time with sub-100ms latency, demonstrating robust performance in challenging outdoor conditions.
