Multi-Station Vision Inspection System

Computer Vision C# / .NET Industrial Automation

Bosch Australia Manufacturing Solutions | March 2024 - Present | Team of 2

The Challenge: First-ever large-scale vision system for the department on an $8M biodegradable packaging line. No templates or previous examples existed. Six inspection stations with 40+ cameras operating at ~0.6 second cycle time. Had to learn C# from scratch while building the system.

What I Built:

  • Unified C# Application: Single multithreaded WPF application managing all 6 stations with 4-12 cameras each, using config files for per-station differences
  • Real-Time PLC Integration: Designed handshake logic for ProfiNet communication with Siemens PLCs, wrote C# wrapper for Hilscher cifX fieldbus card
  • SQL Logging System: Implemented SQL Server Express across all stations for complete product traceability
  • Asynchronous Pipeline: Achieved sub-second inspection through carefully designed multithreaded architecture separating UI, PLC polling, and parallel image acquisition
  • Resilient Design: Added automatic reconnect logic for graceful recovery from camera and device failures

Technical Challenges Overcome:

  • Resolved race conditions requiring complete architecture redesign
  • Network troubleshooting: configured NICs, managed DHCP, resolved packet collisions and dropped frames across high-bandwidth camera network
  • Mid-project feature additions and performance refactoring to meet strict cycle time requirements
  • Presented live demo to customer in workshop - nerve-wracking as intern on system central to their production line

Technical Stack:

C#, .NET, WPF, HALCON, SQL Server, Siemens ProfiNet, Multithreading, Computer Vision, Network Configuration

Impact:

System successfully deployed to production and running reliably. Architecture became department blueprint for future vision systems, with my classes and design patterns reused by other engineers, saving significant development time.

IREC 2025 Launch - Project Zenith

  • Electrical Cabinet Design: Designed and constructed complete DIN rail system housing power supplies, networking, Raspberry Pi, LabJack DAQ, motor drivers, and relays

  • Distributed Control System: Integrated LabJack DAQs (Ethernet), STM32 microcontrollers, and Raspberry Pi using RS422, CAN, and MQTT protocols
  • Software Architecture: Developed multithreaded Python backend with state machines for fill, ignition, and abort sequences
  • SCADA Interface: Created Ignition SCADA interface for real-time monitoring, telemetry, and safety interlocks
  • Data Acquisition: Monitored and controlled 20+ signals across engine and ground station with MQTT database logging and high-rate local telemetry

IREC 2025 Competition Experience:

  • Co-presented control and telemetry architecture at podium session - directly contributed to Jim Furfaro Award
  • Set up launch pad and engine systems under tight time constraints
  • Crisis management: When propellant sensor failed night before launch, stayed up debugging with propulsion lead until successful resolution
  • Operated control station during hot-fire and cold-flow testing, debugging anomalies under pressure

Python, C, RS422, CAN, MQTT, LabJack, STM32, Raspberry Pi, Ignition SCADA, SolidWorks, Creo, DIN Rail Systems, Cable Fabrication
